# FlexMusic 当前产品范围与路线图

## 1. 当前产品定位

FlexMusic 当前是一款以 Android 为主的音频应用，已经具备以下几条主能力线：

- 本地与在线统一播放
- 在线搜索与搜索结果播放
- 睡眠白噪声 / 电台
- 音频转码
- 用户登录与资料管理

项目仍处于“功能逐步落地”的阶段，当前文档以实际完成部分为准，不把未实现功能写成已支持。

## 2. 当前可用功能

### 2.1 播放

- 全屏播放器
- 迷你播放器
- 播放队列
- 顺序 / 随机 / 单曲循环 / 单曲循环次数
- 倍速
- seek
- 最近播放记录

### 2.2 在线搜索

- 多 scope 搜索
- 搜索建议
- 搜索历史
- 热搜入口
- 单曲播放
- 加入下一首 / 加入队列
- 播放全部

### 2.3 本地音乐

- 通过 SAF 导入本地音频
- 本地曲库展示
- 删除时兼容 `file://` 和 `content://`
- 转码产物自动导入本地曲库

### 2.4 睡眠

- 默认白噪声 / 氛围音
- 电台精选与搜索
- 定时关闭
- 30 秒淡出

### 2.5 转码

- 单文件输入
- MP3 / FLAC / OGG / WAV 输出入口
- 输出导入本地曲库

### 2.6 用户系统

- 邮箱 + 密码注册
- 邮箱或用户名登录
- 会话恢复
- 头像上传
- 资料编辑

## 3. 当前未完成的能力

以下仍属于后续规划，不应当被当作现有能力：

- 下载功能完整实现
- 多 provider 聚合搜索
- 歌手 / 专辑 / 歌单详情页
- 后台播放通知和锁屏控制
- 真正的多轨睡眠混音
- 转码队列与任务历史
- 电台官方目录聚合和健康检查体系

## 4. 当前页面结构

主入口：

- `MainActivity`
  - 首页
  - 我的
  - 睡眠

次级页面：

- 搜索页
- 收藏页
- 最近播放页
- 本地音乐页
- 转码页
- 设置页
- 全屏播放器

## 5. 当前开发原则

后续继续扩展产品能力时，保持以下原则：

- 以当前落地代码为准更新文档
- 设计稿和未来规划必须明确标为“未实现”
- 网络能力统一下沉到 `core_network`
- 业务编排放在 `core_data`
- 播放和转码继续保持 Java/UI 与 native 核心分层
